Container queries

A project card can be wide in the main area and narrow in a sidebar within the same viewport. Media queries only know the viewport width. Container queries read an ancestor container’s available space and adapt its children.

Same viewport, different space: only the lower card responds to its container.

Remember

  • container: project-card / inline-size names the query container and enables size queries along the inline axis.
  • Queries style descendants, not the container itself. The wrapper must receive its space from the surrounding layout.
  • The preview uses 700px for the media query and 360px for the container query. Change the slider and then the window width.
  • 1cqi is 1% of the query container’s inline size. clamp() bounds the font size.
  • Without container query support, the single-column base layout remains readable. Media queries remain useful for global page layouts.
  • The slider also works with arrow keys, Home and End.

Before: viewport only

<style>
  .card { display: grid; grid-template-columns: minmax(0, 1fr); gap: 1rem; }
  .card > div { min-width: 0; overflow-wrap: anywhere; }
  @media (min-width: 700px) {
    .card { grid-template-columns: 5rem minmax(0, 1fr); }
  }
</style>

After: component context

<style>
  .card-space { container: project-card / inline-size; }
  .card { display: grid; grid-template-columns: minmax(0, 1fr); gap: 1rem; }
  .card > div { min-width: 0; overflow-wrap: anywhere; }
  .card h2 { font-size: 1rem; }
  @container project-card (min-width: 360px) {
    .card { grid-template-columns: 5rem minmax(0, 1fr); }
    .card h2 { font-size: clamp(1rem, 4cqi, 1.3rem); }
  }
</style>
