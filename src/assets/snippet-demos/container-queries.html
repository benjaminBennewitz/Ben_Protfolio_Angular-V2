Container Queries

Eine Projektkarte kann im Hauptbereich breit und in einer Sidebar schmal sein – im selben Viewport. Media Queries kennen nur die Fensterbreite. Container Queries lesen den verfügbaren Platz eines übergeordneten Containers und passen dessen Kinder an.

Gleicher Viewport, anderer Platz: Nur die untere Karte reagiert auf ihren Container.

Merken

  • container: project-card / inline-size benennt den Query-Container und aktiviert Größenabfragen entlang der Inline-Achse.
  • Die Query gestaltet Nachfahren, nicht den Container selbst. Der Wrapper muss seinen Platz vom umgebenden Layout erhalten.
  • Die Vorschau verwendet 700px für die Media Query und 360px für die Container Query. Ändere den Regler und danach die Fensterbreite.
  • 1cqi entspricht 1% der Inline-Größe des Query-Containers. clamp() begrenzt die Schriftgröße.
  • Ohne Container-Query-Support bleibt das einspaltige Basislayout lesbar. Die Medienregel bleibt sinnvoll für globale Seitenlayouts.
  • Der Regler ist auch mit Pfeiltasten, Home und End bedienbar.

Vorher: nur Viewport

<style>
  .card { display: grid; grid-template-columns: minmax(0, 1fr); gap: 1rem; }
  .card > div { min-width: 0; overflow-wrap: anywhere; }
  @media (min-width: 700px) {
    .card { grid-template-columns: 5rem minmax(0, 1fr); }
  }
</style>

Nachher: Komponentenkontext

<style>
  .card-space { container: project-card / inline-size; }
  .card { display: grid; grid-template-columns: minmax(0, 1fr); gap: 1rem; }
  .card > div { min-width: 0; overflow-wrap: anywhere; }
  .card h2 { font-size: 1rem; }
  @container project-card (min-width: 360px) {
    .card { grid-template-columns: 5rem minmax(0, 1fr); }
    .card h2 { font-size: clamp(1rem, 4cqi, 1.3rem); }
  }
</style>
