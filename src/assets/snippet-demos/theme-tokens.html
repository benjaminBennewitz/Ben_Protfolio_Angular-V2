Theming mit Tokens

Statt Farben in jeder Komponente zu wiederholen, benennen semantische Tokens ihre Aufgabe: Fläche, Text, Rahmen oder Akzent. Das Theme tauscht diese Werte aus; die Komponente und ihre Zustände verwenden dieselben Regeln.

Eine Komponente. Zwei Themes.

Semantische Tokens definieren Fläche, Text, Rahmen und Akzent.

Fehler: Gib eine vollständige E-Mail-Adresse ein.
--surface · --text · --muted · --border · --accent · --on-accent · --error

Merken

  • Primitive Tokens beschreiben konkrete Werte (z. B. Blau 700); semantische Tokens beschreiben deren Aufgabe (--accent). Für kleine Beispiele reicht die semantische Ebene.
  • prefers-color-scheme berücksichtigt die Systempräferenz. Eine explizite data-theme-Auswahl hat Vorrang; System entfernt den Override.
  • color-scheme steuert unter anderem native Formularelemente. Es ersetzt keine eigenen Farb-Tokens.
  • Fokus, Hover, Active, Disabled und Fehler brauchen passende Werte in beiden Themes. Prüfe Textkontrast, Rahmen und Fokus getrennt.
  • Fehler werden durch Text und aria-invalid vermittelt, nicht nur durch eine rote Farbe.
  • Der Theme-Schalter hier verändert nur die Vorschau. Das Portfolio-Theme bleibt unabhängig.

Nachher: semantische Tokens

<style>
  :root {
    color-scheme: light;
    --surface: #fff; --text: #172033; --muted: #465369;
    --border: #69778c; --accent: #2148b2; --on-accent: #fff;
    --error: #ac1731;
  }
  @media (prefers-color-scheme: dark) {
    :root:not([data-theme]) {
      color-scheme: dark;
      --surface: #121c30; --text: #f2f5ff; --muted: #bcc6dd;
      --border: #91a1bd; --accent: #b7caff; --on-accent: #142347;
      --error: #ffb3c1;
    }
  }
  :root[data-theme="dark"] {
    color-scheme: dark;
    --surface: #121c30; --text: #f2f5ff; --muted: #bcc6dd;
    --border: #91a1bd; --accent: #b7caff; --on-accent: #142347;
    --error: #ffb3c1;
  }
  .card { padding: 1rem; background: var(--surface); color: var(--text); }
  .card input { padding: .5rem; background: var(--surface); color: var(--text); border: 1px solid var(--border); }
  .card button { padding: .5rem; background: var(--accent); color: var(--on-accent); border: 1px solid var(--accent); }
  .card button:hover:not(:disabled) { background: var(--surface); color: var(--accent); }
  .card button:active:not(:disabled) { transform: translateY(1px); }
  .card button:disabled { color: var(--muted); background: var(--surface); border-color: var(--border); }
  .card :is(input, button):focus-visible { outline: 2px solid var(--text); outline-offset: 3px; }
  .card [aria-invalid="true"] { border: 2px solid var(--error); }
  .error { color: var(--error); }
</style>
<button type="button" data-theme-choice="light">Hell</button>
<button type="button" data-theme-choice="dark">Dunkel</button>
<button type="button" data-theme-choice="system">System</button>
<article class="card">
  <h2>Projekt</h2>
  <label>Name <input type="text"></label>
  <label>E-Mail <input type="email" value="ben@" aria-invalid="true" aria-describedby="email-error"></label>
  <p id="email-error" class="error">Fehler: E-Mail-Adresse unvollständig.</p>
  <button type="button">Öffnen</button>
  <button type="button" disabled>Deaktiviert</button>
</article>
<script>
  document.querySelectorAll('[data-theme-choice]').forEach(button => {
    button.addEventListener('click', () => {
      const theme = button.dataset.themeChoice;
      if (theme === 'system') delete document.documentElement.dataset.theme;
      else document.documentElement.dataset.theme = theme;
    });
  });
</script>
