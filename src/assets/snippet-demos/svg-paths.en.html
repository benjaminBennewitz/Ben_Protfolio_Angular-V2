Understanding SVG paths

An SVG path is a sequence of drawing commands. The preview connects the d attribute to two movable control points, showing how tangents affect the curve direction and shape.

Drag the control points or use the sliders.

M 25 140 C 80 20, 220 20, 275 140

Remember

  • viewBox="0 0 300 180" defines the internal coordinate system. X grows to the right and Y downwards.
  • M moves the pen, L draws a line, H/V draw horizontally/vertically and Z closes the path.
  • C uses two control points; Q defines a quadratic Bézier curve with one control point.
  • Uppercase commands use absolute coordinates. m/l/c/q are relative to the current point; the initial m is relative to the origin.
  • Control points usually do not lie on the curve. They set the start and end tangents.
  • Decorative SVGs use aria-hidden="true". Informative SVGs need role="img" and an accessible name. Sliders provide a keyboard alternative to dragging.

Before: compact path

<svg viewBox="0 0 300 180">
  <path d="M25 140C80 20 220 20 275 140" fill="none" stroke="currentColor"/>
</svg>

After: path and guides

<svg viewBox="0 0 300 180" role="img" aria-labelledby="curve-title">
  <title id="curve-title">Bézier curve with control points</title>
  <!-- M: start. C: control point 1, control point 2, end. -->
  <path d="M 25 140
           C 80 20, 220 20, 275 140"
        fill="none" stroke="currentColor" stroke-width="3" />
  <!-- Guides from start/end to their control points. -->
  <path d="M 25 140 L 80 20 M 275 140 L 220 20"
        fill="none" stroke="currentColor" stroke-dasharray="3 3" />
  <circle cx="80" cy="20" r="4" fill="currentColor" />
  <circle cx="220" cy="20" r="4" fill="currentColor" />
</svg>
